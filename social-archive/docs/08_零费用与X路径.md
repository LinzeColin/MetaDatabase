# 零费用合同与 X 获取路径

Social Archive 的 Golden Path 不依赖任何付费 API。X 默认使用以下免费路径：

1. Chrome 扩展读取当前已加载的书签或点赞卡片；
2. Social Archiver 免费导出到 Markdown/Obsidian 后，由 Social Archive 监听导入；
3. 平台账户数据导出后，通过标准导入入口进入资料库。

官方 X API 默认硬关闭。只有部署人已经从账户控制台确认该具体权益不会产生任何费用，才可把 `SOCIAL_ARCHIVE_X_API_ZERO_COST_CONFIRMED` 设为 `true`。仅提供 Token 不会绕过这道门。任何不确定情况都保持关闭，不影响当前页面保存、统一索引、搜索、导出和 L0/L1/L3 归档。
