# 产品需求与范围

## 用户问题

用户在不同平台形成了收藏、点赞、稍后看、收藏夹和网页资料，但平台可能删除内容、改变接口、限制导出或让历史关系难以检索。现有工具通常只解决下载、网页归档、书签管理或单个平台中的一个环节；用户需要一个可以直接使用、零付费、零技术门槛、跨平台并具有清晰降级路径的个人档案系统。

## 核心价值

1. **先拿到内容**：优先复用成熟 Worker，失败时仍可保存当前页面。
2. **再确保不丢**：L0 关系、L1 文本与元数据、L3 媒体按哈希去重并多副本保存。
3. **统一找到**：在一个中文 PWA 中按平台、关系、收藏夹、标签、时间和全文检索。
4. **不会误删**：不完整扫描不改变关系；取消关系需要两次完整扫描缺失或明确事件。
5. **永不收费**：所有外部付费能力默认禁用，超过免费硬门自动暂停 L3。
6. **单点失效不连坐**：每个平台、Worker、对象副本和投影独立熔断。

## 当前版本范围

- 九类来源：通用网页、X、Reddit、Instagram、TikTok、小红书、抖音、快手、B站。
- 关系类型：收藏、点赞、稍后看、收藏夹成员、浏览器手动保存、导入。
- 归档层级：L0、L1、L3 默认；L2 手工 WARC/WACZ/截图导入。
- 获取路径：官方 OAuth/API/导出、Social Archiver Markdown/Obsidian 导入、Chrome 当前页采集、隔离 Worker/CLI。
- 浏览：Feed、Grid、Detail、平台健康、存储配额、新手向导。
- 输出：Private-Database、R2、OCI、GitHub Release、Markdown/Obsidian、Notion CSV/Markdown、Netscape Bookmark、ArchiveBox URL 队列、WACZ 目录。
- 运维：systemd、Docker Compose、健康检查、备份恢复、配额熔断、状态投影、回滚。

## 非目标

- 不建设平台级通用爬虫服务或对第三方账号进行批量监控。
- 不绕过访问控制、验证码、签名算法、设备风控或平台限制。
- 不代表用户取得其无权访问、下载或再分发的内容。
- 不对所有平台承诺永远自动全量同步；自动化必须受平台能力与用户授权约束。
- 不把 Notion、Karakeep、Linkwarden、ArchiveBox 或 Social Archiver 变成新的事实源。
- 不在 v0.0.0.4 引入付费 AI、付费向量数据库或付费 API。

## OKR 与 Kill Criteria

| 目标 | 关键结果 | 测量 |
|---|---|---|
| 每个平台形成可用闭环 | 每个平台至少一次 `读取→L0/L1→L3→检索→恢复` Canary | 冻结 Acceptance 与证据包 |
| 系统整体不因单平台失效 | 任一 Worker 断开后，其他平台与当前页采集仍可用 | 故障注入 |
| 零付费 | 所有账单能力关闭；达到硬门不产生上传或下载任务 | Quota Oracle |
| 不误删关系 | Partial scan 后关系数量不减少；两次 complete absent 才关闭 | Fixture 回放 |
| 小白可用 | 新用户按向导在 5 个操作内保存当前页并在库中打开 | 人工验收脚本 |

停止或降级规则：某平台连续两条合法获取路径均失败且真实 Canary 失败，则该平台标记“降级/手动”，不得阻塞发布；对象副本不足时标记风险并继续本地暂存，达到配额硬门时只暂停 L3；若无法保证凭证不落盘或第三方许可边界，则禁用对应 Adapter。
