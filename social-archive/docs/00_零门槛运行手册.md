
# Social Archive 零门槛运行手册

## 你最终只需要两个入口

1. 打开 `https://social-archive.linzezhang.com`；
2. 安装 Social Archive Chrome 扩展。

你不需要安装或分别打开 Karakeep、Linkwarden、ArchiveBox、XHS-Downloader、DouK、KS-Downloader、bilibili-cli、gallery-dl、yt-dlp 或 Instaloader。它们由 Social Archive 在后台自动选择和降级。

## 第一次使用

1. 打开插件安装页，按上面的六步装好（Chrome Web Store 上架前用官方 ZIP 安装包）；
2. 装好后回到资料库，点“连接第一个账号”；
3. 在“账号同步中心”授权常用平台；
4. 选择 Markdown、Notion、Obsidian、GitHub Private；
5. 打开任意本人有权访问的页面，点击“保存到我的档案馆”。

没有安装插件时，仍可在首页粘贴链接保存，也可使用 PWA 分享。

## 现在这一版能做什么、不能做什么

**这一节是实况，不是愿景。** 2026-08-04 的真实状态：

| 来源 | 能不能自动同步收藏 | 现在能做的 |
|---|---|---|
| Chrome 书签 | **能**（实测 62 条全量导入） | 点“连接账号”一次即可 |
| X / Instagram | 能，但要先连接账号 | 在设置页连接，登录状态会加密保存 |
| 小红书 / 抖音 / B站 / 快手 | **还不能** | 打开任意一条内容，点插件的“保存到我的档案馆” |

国内四个平台的自动读取通道在上一版被拆掉后，替代方案还没接完——那一步需要
在你已登录的平台页面上配合一次。**在那之前，界面不会给这几个平台画“立即同步”
按钮**，免得你点一个不可能成功的东西。

已经存进来的内容不受影响：搜索、筛选、打开详情、导出都正常。

## 每天怎么用

- 当前页：点击扩展中的“保存到我的档案馆”；
- 收藏列表：在“账号同步中心”连接对应平台，之后由后台队列同步，不需要每次手点。
  （原文写的是点“读取当前列表”、“只读取当前可见内容，不自动无限滚动”——
  那描述的是 v0.0.0.6 之前的 DOM 抓取器，**T03 已把它整条删除**。
  现在国内三源走的是「在你自己的浏览器里拦截平台自己发出的收藏接口响应」，
  见 `DOMESTIC_WORKERS_ZH.md`；不合成请求、不读 Cookie、不绕验证码。）
- 查看：网站进入资料库搜索、筛选和打开详情；
- 失败：任务中心只显示一个修复动作，可以重试；
- 默认保存 L0/L1/L3；L2 页面快照默认关闭。

## 不想要了怎么办（每一步都能撤）

连上的东西都能断开，**而且断开不会删掉你已经存下的内容**。

| 你想做的 | 在哪里 | 会发生什么 |
|---|---|---|
| 让某个账号别再自动同步 | 账号同步中心 → 该账号 → 点“断开” | 不再自动跑；已存的内容一条不少；随时可以重新连接 |
| 删掉服务器上保存的登录状态 | 扩展设置页 → 该平台 → 点“撤销登录状态” | 服务器上加密保存的登录信息立即删除，浏览器那边的读取权限也一并交还 |
| 停掉正在跑的一次同步 | 账号同步中心 → 点“暂停”或“取消” | 只影响这一次，已经取到的都留着 |

“断开”和“撤销登录状态”是两件事，分开做：你可以只让它别再自动跑，
而保留登录状态；也可以两个都做。

只有 X、Instagram、YouTube 会在服务器上保存登录状态（因为取内容要在服务器上跑）。
小红书、抖音、B站、快手的 Cookie 一步都不会离开你的浏览器，也就没有可撤销的东西。
任何平台的密码都永远不会被索要或保存。

## 状态怎么理解

- 未授权：还没有允许扩展访问该网站；
- 已授权：浏览器权限已授予，但还没有完成真实读取；
- 已连接：真实读取 Probe 成功；
- 降级可用：首选引擎失败，但仍可保存当前页；
- 需要处理：只有一个明确下一步。

## 出问题时

普通用户只进入任务中心点“重试”或按唯一提示操作。Build Agent 的诊断、备份和回滚命令见任务包根目录 `11_AGENT/BUILD_AGENT_RUNBOOK.md`；普通用户不运行命令、不填写 Token/Cookie，也不接触服务器。
