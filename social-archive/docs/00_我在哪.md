# 我在哪：Social Archive 的最短使用路径

## Build Agent 完成 Stage 0 后

1. 在服务器进入 `social-archive/`。
2. 运行 `bash scripts/install.sh`。
3. 运行 `bash scripts/start.sh`。
4. 打开 `http://127.0.0.1:18765`；远程部署完成后打开 `https://social-archive.linzezhang.com`。
5. Chrome 打开 `chrome://extensions`，启用开发者模式，加载 `apps/browser-extension/`。
6. 在任何你本人有权访问的页面点击扩展，选择“保存当前页面”。这是所有平台永远存在的兜底路径。

## 平台顺序

- Stage 1：X、Reddit、Instagram、TikTok/通用网页。
- Stage 2：小红书、抖音、快手、B站。
- Stage 3：统一聚合、搜索、筛选、详情页、新手向导，以及可选 ArchiveBox、Karakeep、Linkwarden、ArchiveWeb.page 投影。
- Stage 4：Notion、Obsidian、GitHub 与标准 Markdown/JSONL 目的地。

## 你只需要理解三个状态

- **可用**：首选连接器和兜底路径均可工作。
- **降级**：首选第三方 Worker 失效，但仍能保存当前页面或导入文件；不会拖垮其他平台。
- **暂停 L3**：免费存储接近硬门，系统继续保存 L0/L1，但暂停媒体下载，绝不产生付费。

## 数据放在哪里

- GitHub Private-Database：结构化事实、文本、关系、对象索引、版本与恢复目录。
- Cloudflare R2：原始媒体与其他对象字节的主副本。
- OCI：对象异地副本。
- GitHub private Release：加密分片的第三副本。
- OVH SQLite：只用于运行中的任务、幂等、Outbox、游标和状态；损坏后可以重建。
