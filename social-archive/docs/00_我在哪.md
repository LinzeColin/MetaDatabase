
# 我在哪：Social Archive 的最短路径

## 普通用户

1. 打开 `https://social-archive.linzezhang.com`；
2. 安装并连接浏览器插件；
3. 打开本人有权访问的网页；
4. 点击“保存当前页面”；
5. 回到资料库搜索、浏览和导出。

扩展尚未安装时，首页仍可粘贴链接保存。任何单个平台失效时，普通网页保存仍可使用。

## Build Agent

技术安装、真实授权、部署、恢复和发布只按任务包 `11_AGENT/BUILD_AGENT_RUNBOOK.md` 执行。不要让普通用户进入 `chrome://extensions`、终端、Docker、服务器端口或 Secret 文件。

## 三个重要状态

- 已授权：权限已经授予；
- 已连接：真实读取成功；
- 降级可用：首选引擎失败，但保底保存仍可工作。
