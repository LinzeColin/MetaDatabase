
# 我在哪：Social Archive 的最短路径

## 普通用户

1. 打开 `https://social-archive.linzezhang.com`；
2. 安装并连接浏览器插件；
3. 打开本人有权访问的网页；
4. 点击“保存当前页面”；
5. 回到资料库搜索、浏览和导出。

任何单个平台失效时，普通网页保存（插件的「保存当前页面」）仍可使用。

> **删掉了半句**（2026-08-14）：这里原来还写着「扩展尚未安装时，首页仍可粘贴链接保存」。
> 实测首页只有三个输入框——搜索、导入时填平台名、上传文件——**没有贴链接的地方**；
> `manifest.webmanifest` 里也没有 `share_target`。**那条路不存在。**
> 它承诺的又正好是**还没装插件的人**，也就是第一次来的那个人。

## Build Agent

技术安装、真实授权、部署、恢复和发布只按任务包 `11_AGENT/BUILD_AGENT_RUNBOOK.md` 执行。不要让普通用户进入 `chrome://extensions`、终端、Docker、服务器端口或 Secret 文件。

## 三个重要状态

- 已授权：权限已经授予；
- 已连接：真实读取成功；
- 降级可用：首选引擎失败，但保底保存仍可工作。
