# 零门槛流程（冻结）

这一份是**冻结的界面契约**。Build Agent 按此实现，不得增加主流程步骤，不得增加需要用户决策的控件。
文案照抄，不要改写成更"专业"的说法。

## 铁律

1. **主流程上永远只有一个显眼按钮。** 用户在任何一屏都不需要判断"我该点哪个"。
2. **永远不出现这些词**：配对码、令牌、endpoint、API、重载、解压、开发者模式（第 3 屏除外，且必须配图文步骤）、配置文件、日志。
3. **任何一次同步结束时如果是 0 条，界面必须说出为什么。** 只显示 "0" 是缺陷，不是状态。
4. **不跳页。** 整个连接流程在同一个页面内推进（分步卡片），不要开新标签让用户在页面间找路。
5. **失败可重试，且重试按钮就在错误旁边。**

## 第 1 屏 · 落地页（未登录）

```
        Social Archive
   把你在各个平台收藏的东西，收进一个地方

        [ 用 Google 登录 ]
        [ 用 GitHub 登录 ]
```

- 没有第三个按钮，没有注册表单，没有"了解更多"。
- 登录成功直接进第 2 屏，不经过任何中间页。

## 第 2 屏 · 状态总览（已登录，未装插件）

```
   你好，<名字>

   ┌────────────────────────────────┐
   │  还差一步就能开始               │
   │  Social Archive 需要一个浏览器  │
   │  插件来读取你自己的收藏。       │
   │                                │
   │        [ 安装插件 ]            │
   └────────────────────────────────┘
```

- 页面自己检测插件是否已安装（扩展注入 bridge 后握手）。装好了自动切到第 4 屏，**不需要用户刷新**。

## 第 3 屏 · 装插件（本流程唯一有技术味道的一屏，必须手把手）

上架 Chrome 应用商店之前，只能用「加载已解压的扩展程序」。这一屏必须做到：

- **一个下载按钮**：`[ 下载插件 ]` → 直接下 zip，文件名固定 `social-archive-extension.zip`
- **四步图文**，每步一句话、一张图（图放 `03_PREBUILT/extension/install-guide/`，由 Build Agent 在真实 Chrome 上截）：
  1. 解压刚下载的文件（双击就行）
  2. 在 Chrome 地址栏输入 `chrome://extensions` 回车
  3. 打开右上角的「开发者模式」
  4. 点「加载已解压的扩展程序」，选中刚才解压出来的文件夹
- **底部一个自检条**：`正在等待插件出现…` → 检测到就自动变成 `✓ 插件已就绪`，并自动进入第 4 屏。
- 如果 60 秒还没检测到，显示：`还没检测到插件。第 4 步选的应该是解压后的文件夹，不是 zip 文件本身。` + `[ 我再试一次 ]`

> **插件更新的口径**：上架之前，每次插件更新都要用户重做一遍这四步，这不可接受。
> 但这不在打通黄金事务的关键路径上，按合同 §4.1「U3 之前不扩范围」**移入 Backlog**。
> 本版本的兜底做法：站点检测到插件版本落后时，在这一屏顶部提示，
> 用户重新选一次解压后的文件夹即可（Chrome 会覆盖同 ID 扩展）。
> 一键更新与 Chrome 应用商店上架见 `09_ROADMAP/BACKLOG.md`。

## 第 4 屏 · 连接平台（核心屏）

一张平台卡片列表。每张卡片只有两种状态：

```
   ┌──────────────────────────────────────────┐
   │  𝕏  X（推特）        未连接   [ 连接 ]    │
   │  📷 Instagram        未连接   [ 连接 ]    │
   │  ▶️  YouTube          未连接   [ 连接 ]    │
   │  🤖 Reddit           未连接   [ 连接 ]    │
   │  🔖 Chrome 书签       未连接   [ 连接 ]    │
   │  📕 小红书            未连接   [ 连接 ]    │
   │  🎵 抖音              未连接   [ 连接 ]    │
   │  📺 哔哩哔哩          未连接   [ 连接 ]    │
   └──────────────────────────────────────────┘

            [ 全部连接 ]
```

**点「连接」之后发生什么（用户视角）：**

- 已经在那个平台登录过 → 卡片直接变 `✓ 已连接（<你的用户名>）`，**没有任何弹窗**
- 没登录过 → 新标签打开该平台首页，顶部飘一条：`请先登录 <平台>，登录后回到这里，它会自动连上`
- 连接失败 → 卡片变红并写明原因，例如 `连接失败：没有在浏览器里找到 X 的登录状态`，旁边有 `[ 重试 ]`

**技术上发生什么（用户不需要知道）：**

- 西方三源（X / Instagram / YouTube）：扩展读取该域 Cookie，转成 Netscape 格式，加密上传
- Reddit：跳 Reddit OAuth 授权页，回调拿 refresh token
- Chrome 书签：申请 `bookmarks` 可选权限
- 国内三源：只记录"已登录"这个事实，**不读取也不上传任何 Cookie**

## 第 5 屏 · 主页（连接完成后，也是日常唯一会看的一屏）

```
   ┌──────────────────────────────────────────┐
   │                                          │
   │           [  全量保存  ]                  │
   │                                          │
   │   上次同步：2026-08-03 21:14              │
   │   已收录 1,284 条 · 来自 7 个来源          │
   └──────────────────────────────────────────┘

   ── 表格（平台分组，关系时间倒序）──
```

- **第一次**按钮写 `全量保存`；跑完之后按钮文案变成 `刷新同步`。除此之外按钮永远只有这一个。
- 点下去之后按钮变成进度条，**逐个来源报进度**：
  ```
  正在同步… X 书签 128 条 ✓ ｜ Instagram 收藏 进行中… ｜ YouTube 等待中
  ```
- 国内三源需要浏览器：进度条里显示 `小红书：正在你的浏览器里读取，请不要关闭标签页`
- **跑完必须给结论**，三种之一：
  - `完成：新增 128 条，跳过 1,156 条已有`
  - `部分完成：6 个来源成功，抖音失败（登录状态已过期，[ 重新连接 ]）`
  - `没有新增。上次同步之后这 7 个来源都没有新的收藏。` ← **注意这句话和"0"不是一回事**

## 错误文案词典（冻结）

界面上出现的失败必须用下面这些话，不得出现英文错误码或堆栈：

| 情况 | 文案 |
|---|---|
| 平台登录状态过期 | `<平台> 的登录状态过期了。[ 重新连接 ]` |
| 浏览器里没找到登录状态 | `没有在浏览器里找到 <平台> 的登录状态。请先在浏览器里登录 <平台>，然后点 [ 重试 ]` |
| Reddit 未授权 | `Reddit 需要单独授权一次。[ 去授权 ]` |
| 国内平台标签页被关掉 | `<平台> 同步中断了，因为标签页被关掉。[ 继续 ]` |
| 平台限速 | `<平台> 请求太频繁，已自动放慢。已经收到的 <N> 条都保住了，稍后会自动继续。` |
| 服务端不可达 | `暂时连不上服务器。你的数据没有丢，[ 重试 ]` |
| 磁盘配额 | `存储空间快满了，已经暂停下载媒体文件，文字和链接还在正常保存。` |
| 没有读取平台页面的授权 | `还没有获得读取 <平台> 页面的授权。请点 [ 连接账号 ]，在浏览器弹出的框里选「允许」。` |
| 平台把视频下载挡住了 | `内容已经存下来了，只有视频/图片文件没取到——<平台> 把下载挡住了。我们不绕过平台的风控，所以这一条会一直是这样；正文和链接不受影响。` |
| 文件格式还处理不了 | `内容已经存下来了，只有那个文件没取到——它的格式我们还处理不了。正文和链接不受影响。` |
| 在浏览器里读页面没成功 | `在你的浏览器里读 <平台> 的页面时没能完成。请打开该平台的收藏页、确认已登录，然后点 [ 重试 ]。` |

> **这一行是 v0.0.0.22 追加的，不是改写。** 上面七句一个字没动。
>
> 追加的理由：这些平台的主机权限在 `optional_host_permissions` 里，
> 连接账号那一步才申请；**没有权限时连标签页的网址都读不到**，
> 于是代码算出空域名，回一句「读不出当前页面的域名」。
> 那把人指向**是不是页面没打开**，而真因是授权没给或被撤销了，
> 下一步在插件里、不在平台页。
>
> 词典里最接近的是那句 `没有在浏览器里找到 <平台> 的登录状态` ——它会把他送回平台页去登录，
> **方向是反的**。这份契约立的时候还没有这条路，所以它表达不了这件事；
> 与其套一句指错方向的话，不如补一行。

## 明令禁止的界面行为

- 显示 `0` 而不说明原因
- 点了按钮没有任何视觉反馈
- 用 `success: true` 的接口返回值当作"同步成功"来显示（v0.0.0.6 就是这么把死锁掩盖掉的）
- 让用户去点"高级"、"设置"、"诊断"才能知道为什么失败
- 任何要求用户复制粘贴一串字符的步骤
