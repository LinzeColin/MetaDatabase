# 可选阅读器：零门槛启动

Social Archive 自有 PWA 是权威聚合界面；Karakeep、Linkwarden、ArchiveBox 只是可替换阅读/归档投影，不会成为第二事实源。

首次安装已自动生成仅本机可读的随机秘密。启动默认组合（Karakeep＋ArchiveBox）：

```bash
bash scripts/start_readers.sh readers
```

单独启动 Linkwarden：

```bash
bash scripts/start_readers.sh linkwarden
```

停止全部：

```bash
bash scripts/stop_readers.sh
```

从 Social Archive 运行 `bash scripts/export.sh`，把 `runtime/exports/latest/bookmarks.html`、`archivebox-urls.txt` 或 Notion CSV 导入对应工具。第三方服务故障不影响 Core、当前页保存或 Canonical Facts。
