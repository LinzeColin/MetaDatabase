# 可选阅读器：一次启动，自动投影

Social Archive 自有 PWA 与 Canonical Store 始终是主产品。Karakeep、Linkwarden、ArchiveBox 只负责成熟的浏览或网页归档体验，任何一个失败都不会影响保存。

## 一键启动

安装后执行：

```bash
bash scripts/start_readers.sh readers
```

该命令启动 Karakeep、Linkwarden 和 ArchiveBox，并只绑定本机端口：
- Karakeep：`http://127.0.0.1:3000`
- Linkwarden：`http://127.0.0.1:3001`
- ArchiveBox：`http://127.0.0.1:8000`

也可单独传入 `karakeep`、`linkwarden` 或 `archivebox` profile；它们只检查各自需要的 Secret，ArchiveBox 不要求 Karakeep 或 Linkwarden 凭据。

首次进入 Karakeep/Linkwarden 创建管理员账户和 API Token，然后重新运行 `python3 scripts/setup_wizard.py`。扩展设置页点击“检查全部连接”；只有真实 Probe 通过才显示已连接和允许勾选“自动导入”。

## 自动行为

- Karakeep：调用 `/api/v1/bookmarks`；
- Linkwarden：调用 `/api/v1/links`；
- ArchiveBox：自动写入去重 URL 队列；高保真抓取属于 L2，默认只保留队列。只有用户显式执行 `SOCIAL_ARCHIVE_L2_ENABLED=true bash scripts/archivebox_sync.sh` 才会提交队列；
- 每条投影有 done/noop/failed 回执；相同内容不重复写入；
- 第三方阅读器不能修改 Social Archive 的 Canonical facts。

停止全部：

```bash
bash scripts/stop_readers.sh
```
