# SA-505 部署兼容性决策

## 已验证事实

真实 OVH 只读盘点发现，原合同硬编码的 `127.0.0.1:8765` 与 `127.0.0.1:8780` 已被无关的在运服务占用；`status.linzezhang.com` 也已承担全域状态站的根路径。直接按原端口启动或将该 hostname 整站改指向 Social Archive 都会破坏现网，属于 SA-505 的停止条件。

## 最小适配

- Core 继续在容器内使用 `8765`，但只映射到 `127.0.0.1:18765`。
- 只读状态服务绑定 `127.0.0.1:18780`。
- 新 Tunnel 仍独立承载资料库和扩展 API 两个产品 hostname。
- 同一 Tunnel 对 `status.linzezhang.com` 采用有序路径路由：`/social-archive.json`、`/social-archive-health` 到 Social Archive 的隔离 loopback；其他既有路径回送本机 Traefik，保持全域状态站可用。
- Cloudflare Free 的 Rate Limit 控制台当前仅提供 10 秒窗口；生产规则使用每 IP `1 次 / 10 秒`，即持续上限 ≤6/min，比原产品下限“≤10/min”更严格。Core 仍保留 10/min 内存后备；此为真实平台兼容性适配，不得在没有新外部验收的情况下放宽。

端口在应用前必须再次只读确认未被占用。适配不降低 Access、Bearer、WAF/Rate Limit、loopback-only、脱敏投影、无公开写入口或默认 404 的原有要求。

## 验收口径

外部验收以 `https://status.linzezhang.com/social-archive.json` 的无缓存脱敏 JSON 为准，而不是接管现有站点根路径。真实 Tunnel、Access、WAF/Rate Limit、回滚快照和现网状态根路径回归都必须记录；任一项失败即回滚，不以本地 fixture 代替。
