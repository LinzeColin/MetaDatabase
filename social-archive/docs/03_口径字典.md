# 口径字典

| 术语 | 唯一定义 |
|---|---|
| L0 | 内容 ID、规范化 URL、来源账号、收藏/点赞/稍后看关系、首次/最近观察时间 |
| L1 | 标题、作者、正文、发布时间、收藏夹、标签、缩略图引用、原始结构化 JSON、文本化字幕 |
| L2 | 页面截图、SingleFile、WARC/WACZ 等浏览证据；本版本默认关闭，仅手工启用 |
| L3 | 原图、视频、音频、字幕、OCR/ASR 文本、关键帧及其对象哈希 |
| Observation | 某次采集实际看见的字段，不直接覆盖历史事实 |
| User Relation | 用户与内容之间的收藏、点赞、稍后看、收藏夹成员或手动保存关系 |
| Scan Receipt | 一次列表扫描的范围、游标、完整性、条目数和失败原因 |
| Complete Scan | Connector 明确证明从起点到终点均成功，无截断、限流或未知缺口 |
| Partial Scan | 任何未能证明完整的扫描；不得用于推断取消收藏 |
| Artifact | 文本、JSON、图片、视频、字幕、OCR/ASR、WACZ 等可寻址制品 |
| Canonical Fact | 已经通过 Outbox 写入 Private-Database 的长期结构化事实 |
| Runtime Journal | OVH SQLite 中可重建的任务、游标、幂等、错误和 Outbox 状态 |
| Projection | 从权威事实可重建的 PWA 搜索索引、Notion、Obsidian、Karakeep 等展示 |
| Zero-spend | 任何路径都不会自动启用付费、超额或按量计费；达到硬门必须停止相应写入 |
| Degraded | 首选路径不可用但仍有合法兜底；不等于整个系统失败 |
