# 任务包的作用

本任务包把旧的空壳网站替换为完整北极星系统，并把非环境工作提前完成。Build Agent 不需要重新研究市场、产品、架构、Schema、接口、测试、监控、恢复或版本命名。

用户可见效果：

- 打开网站即看到本分钟唯一建议、有效期和下一次更新时间；
- 可以查看每个 Skill 的独立结论、中枢如何协调和为什么选择最终建议；
- GitHub 新增或更新 Skill 后，系统自动发现、验证和热更新；
- 单个 Skill 损坏时隔离新候选并继续使用上一稳定版本；
- 无数据或链路未完成时明确显示 SYSTEM_BLOCKED，拒绝空壳假完成；
- 服务重启后 systemd 自动恢复，每分钟继续运行。
