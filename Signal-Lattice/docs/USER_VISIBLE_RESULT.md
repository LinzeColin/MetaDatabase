# 用户可见结果

首页第一屏只显示一个本分钟结果：行动、标的、价格区间、仓位区间、有效期、持有周期、置信度、主要理由、主要反对意见和下一次更新时间。

用户可以下钻查看：

- 所有 Active Skill 是否已在本分钟运行；
- 每个 Skill 的独立结论、证据和失效条件；
- 中枢去重了哪些重复证据；
- 哪些 Skill 互相冲突；
- 量化、费用、流动性、容量和组合风险门；
- Skill 的 GitHub 版本与兼容状态；
- 历史可靠性权重如何变化。

验收不能只检查网页 HTTP 200；必须证明真实 Skill 数、完整运行数、唯一建议数、数据库、API 和页面相互一致。
