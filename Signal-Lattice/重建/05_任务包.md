## 架构（两层）

```
研究层（每日 + 盘中每 15 分钟增量，systemd timer）
  SEC 申报采集 → 时点正确的事实库（SQLite，按申报日入账，保留原值与重述值）
  → 候选池（市值 3 亿–50 亿美元且新浪口径也不超、近 18 个月有 10-K/10-Q 的本土申报人、价格 ≥3、20 日成交额中位 ≥300 万美元）
  → 5 个分支各自在独立子进程里对全池打分 → 不可变证据快照 evidence-<hash>.json（含 shortlist 前 30）

实时层（每 60 秒，保留现有 loop）
  读最新证据快照 + 拉 shortlist 与 IWM 的行情 → 时效门（沿用交易时间算法）
  → 中枢（证据根去重、正反冲突、可靠性权重、硬门）→ 唯一建议 / NO_ACTION / SYSTEM_BLOCKED
  → 记分簿（只追加）→ 页面
```

## 块

**B1 事实库与 SEC 采集** `src/signal_lattice/evidence/`
- 免 key：`company_tickers_exchange.json`、submissions、companyfacts、Form 4 XML、8-K item、每日索引；UA 头、≤5 次/秒、ETag 缓存、失败重试有上限。
- 事实表按 `filed` 入账，字段含 accession、form、period、filed、value、原文 URL；查询只取 `filed ≤ as_of`。
- 退市/改名股保留（防幸存者偏差）。
- 验收：对 5 家真实公司跑一遍，落盘行数与 SEC 网页核对一致；单测覆盖「重述不覆盖原值」「as_of 之前看不到之后的申报」。

**B2 候选池与行情** `src/signal_lattice/universe.py`
- 市值 = SEC 流通股 × 价格；价格/成交额来源以调研 B 组实测通过的为准。
- 验收：生成当日候选池，打印分布（市值分档计数），ETF 数、>50 亿数、外国发行人数均为 0；单测钉住门槛。

**B3 五个分支** `src/signal_lattice/branches/{bottleneck,commercial,event_atlas,foresight}.py`（`lead_lag.py` 保留）
- 瓶颈：按 Skill `references/scoring_model.md` 五维表＋几何平均＋四门否决；每个因子写明取自哪个 XBRL 概念或哪类原文关键词，拿不到的因子记「无证据」而不是填中值。
- 商业机会：按 Skill `scoring-and-maturity.md` 的基础分、风险扣分、置信度、E0–E5 门禁。
- 事件航图：Form 4 只取代码 P，剔除 10b5-1、小额、例行买入者；S-3/424B 稀释、8-K 1.01、13D、财报日；每类事件的历史基准由全池事件研究算出。
- 股势前瞻：逻辑回归，特征来自前三个分支＋52 周高点折价＋波动率；按申报日滚动训练，Brier 不优于基准概率则 `ABSTAIN`。
- 参数以数据形式放 `Stock_Skill/<skill>/runtime/params.json`（带 schema），每轮校验 registry 版本，坏了用上一次好的。
- 每个分支在独立子进程运行，只读快照文件，资源受限。
- 验收：5 个分支在真实候选池上都产出非空结论；每个 `PASS` 结论都带至少一条 SEC 原文链接；任何分支不得出现 `UNIMPLEMENTED`。

**B4 中枢、记分簿、回测**
- 中枢：证据根（accession）去重；可靠性权重来自记分簿命中率，样本 < 8 等权。
- 记分簿：每日收盘追加建议、价格、IWM、随机同档对照；20/60 交易日后结算超额与命中率＋Brier。
- 回测：时点正确、滚动前推、扣费（按成交额分档估成本）、安慰剂（窗口后移）；OOS 窗口 < 6 不公布数字。
- 验收：回测报告落盘；页面与 API 的原始响应里对证据不足的数字做反向断言（沿用旧规则）。

**B4.5 规则自证门**（B4 回测显示规则没有信息量之后加的）`hub.proof_gate`
- 发布唯一建议（研究跟进·看多）前，满足任一才开门：(a) 回测：样本外窗口 ≥ 6，唯一建议 20 日净超额均值相对 IWM > 0、相对同档随机 > 0，且安慰剂均值 < 正式；(b) 前向：记分簿里已结算的候选（影子候选 + 正式建议）≥ 8 条，命中率 ≥ 55%，平均超额 > 0。
- 门没开：决策 NO_ACTION，原因写人话；照常算出「如果发布会选谁」记为影子候选（记分簿 shadow 表，单独统计、20/60 日结算、带随机对照），观察名单前 5 照给。
- 证据不足的一半（回测窗口 < 6 / 前向 < 8）在判定结果里就没有收益数字。
- 验收：`tests/test_proof_gate.py`（门关/(a)/(b)/安慰剂更好/反向断言）。

**B5 页面与 API**
- 版式不动（结论优先、导航九个栏目），内容换成：唯一建议（公司名、代码、市值、所属分支结论）、一手原文列表（可点开）、失效条件与是否触发、前向记分、候选比较（前 30）。
- 验收：桌面和手机宽度各截图；盘中、午休/收盘、周末三种状态各看一遍。
