# 02｜调研依据（2026-09-30，diaoyan 中档，3 个 Sonnet 取材，关键原文本人复核）

问题：运行期零模型、只用免费一手数据，怎样给中小盘出可信的研究建议？支撑的决定：推翻重建（5 个 Skill 真参与、中小盘）还是只改候选池。结论：推翻重建，但信号取舍按下表，不照搬 Skill 里所有因子。

## 信号取舍

| 信号 | 用法 | 依据（来源 × 印证） |
|---|---|---|
| 内部人「机会型」买入（剔除过去 3 年同月例行买入者） | 事件航图主信号 | Cohen-Malloy-Pomorski，价值加权 82bp/月，例行型≈0。原文摘要本人读过 https://www.nber.org/papers/w16454 （一手 × 单一；2007 年后复制未查到） |
| 年报/季报措辞变化（Lazy Prices，相邻期文本相似度） | 商业机会风险扣分 + 前瞻特征 | 做空「改动者」、做多「未改动者」月 alpha 最高 188bp，1995-2014。本人读过摘要 https://www.nber.org/papers/w25084 （一手 × 单一） |
| 净股本发行 / 稀释 | 全分支扣分、失效条件 | 微盘缓解后仍显著的少数异象之一（Hou-Xue-Zhang https://www.nber.org/papers/w23394 ，一手 × 单一） |
| 毛利能力 | 质量过滤，不单独加分 | 大盘有效，与投资效应混杂（Novy-Marx；HXZ）（一手 × 有矛盾） |
| 客户-供应商联系、订单积压 | 只作瓶颈证据标记，不承诺收益 | Cohen-Frazzini 发现后样本衰减；积压仅一篇 2003 年研究（二手 × 弱） |
| 「单一来源」「产能受限」等关键词 | 只作瓶颈证据标记 | 没找到收益实证（查了，没有） |
| 盈余公告后漂移 | 不用 | 微盘 2016 年起消失（Martineau，一手 × 单一） |

## 数据源（本人实测复核 SEC 与新浪）

- 能接：SEC data.sec.gov（submissions / companyfacts / frames / Form 4 XML），免 key，须带声明性 User-Agent，全 IP ≤10 次/秒。frames 一次取全市场流通股（4556 家，本人实测）。
- 能接：新浪 `hq.sinajs.cn/list=gb_xxx`（需 Referer），一次多只，含价格、成交量、市值、流通股（本人实测）；美股日线新浪 `US_MinKService.getDailyK`、腾讯 `fqkline`（`.OQ` 后缀）。灰色源，无公开条款，做双源互校。
- 能接：Nasdaq Trader 符号目录（剔除 ETF/测试股）。
- 条件接：SEC 全文检索 efts（robots 403，非文档化接口，只当线索）。客户集中度 XBRL 全市场仅 28 个点，要从文本取。

- 第二期（A 股/港股）：巨潮公告、东方财富数据中心、披露易均免登录可取，条款未读到，归灰色源，第二期再接。

## 必须照做的坑

1. 基本面按申报日入账，重述不覆盖原值（前视偏差）。
2. 候选池保留退市股（幸存者偏差）。
3. 下限 3 亿美元市值，避开微盘；回测扣成本、报可容纳资金。
4. 基准并列 IWM、同档随机对照；做窗口后移安慰剂。
5. 规则试多了要做 deflated Sharpe；复杂模型对不过简单基线（52 周高点折价 + 波动率）就用简单的。
6. 命中率只从申报日之后算；亏损的建议留在记分簿里。
