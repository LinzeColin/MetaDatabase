# 可视化契约

`atlas.html` 是分析制品，不是前端应用或服务。

硬要求：

- 单文件、UTF-8、无需 CDN、无需联网；
- 全局中文；
- 可切换“同期相关”和“时延方向”；
- 可按收益尺度和证据状态筛选；
- 同期相关使用无向线，时延关系使用箭头；
- 地图之外必须提供表格与证据详情；
- 图上的关系只来自当前筛选下 `CONFIRMED` 的结果；
- 不使用颜色作为唯一信息载体，负相关同时使用虚线；
- 页面固定显示“统计相关或领先不等于现实因果或投资建议”。

宿主可将该 HTML 嵌入现有系统，也可以直接消费 `analysis.json`、`co_movement.csv`、`correlation_matrix.csv`、`matrix.csv` 和 `edges.csv` 构建自身界面。宿主界面不得改变底层证据状态含义。
