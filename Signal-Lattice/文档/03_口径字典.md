# 03｜口径字典

- **DATA_READY**：本轮报价、研究快照、新鲜度门全部通过，结论可展示；否则 `SYSTEM_BLOCKED` 且 `/health/ready` 返回 503。
- **RECOMMENDATION / NO_ACTION / SYSTEM_BLOCKED**：页面分别写「研究跟进（看多）」「本轮不给建议」「本轮不出结论」。
- **规则自证门**：回测或前向记分证明规则有信息量才开；前向样本够而不达标是一票否决。门没开时决策 NO_ACTION。
- **影子候选**：门没开时仍算出「如果发布会选谁」，只记记分簿 shadow 表、不发布，同样 20/60 日结算并带随机对照。
- **PASS / ABSTAIN / FAILED**：分支收据。FAILED 不缓存，同一快照再跑时重跑。
- **snapshot_hash**：不可变证据快照的内容哈希，5 个分支收据必须相同。
- **证据根**：SEC 申报的 accession；同一份申报只算一次。
- **行情新鲜度**：来源时间到现在的交易时段秒数 ≤ 声明时延 + 180 秒。
- **OOS_HISTORY_INSUFFICIENT**：样本外窗口 < 6，不公布收益数字；前向已结算样本 < 8 写「样本不足」。
- **COLD_START_EQUAL**：可靠性样本 < 8 时分支等权。
