# 03｜口径字典

- **Observed**：GitHub 已发现的最新 Skill，不可直接形成行动。
- **Validated**：通过身份、完整性、兼容、安全和回放的候选。
- **Active**：通过晋级门的当前运行快照。
- **Policy IR**：从 Skill 中确定性提取的可执行政策；未知语义不得猜测。
- **Claim**：主体、命题、方向、期限和 as-of 的结构化结论。
- **Evidence Root**：去重后的独立根证据。
- **NO_ACTION**：任一硬门失败时的强制行动类型。
- **SEALED_TASKPACK**：Owner 已批准、可交给 Build Agent 的最终开发任务包；不等于生产发布 PASS。
- **FROZEN_CANDIDATE**：完成真实环境绑定、精确上游 Seal 和构建后形成的不可变候选。
- **Status Tier-0**：项目运行、登记、耦合、备份和恢复的最高权限控制面与只读投影入口。
