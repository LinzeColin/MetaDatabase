# 02｜系统架构

```text
GitHub 固定 Skill 来源
→ Observed / Validated / Active 三状态
→ 确定性 Policy IR 与平权 Skill Fabric
→ Claim / Evidence / Conflict Graph
→ Point-in-time Quant Assurance
→ Consensus / Risk Veto
→ Action Packet 或 NO_ACTION
→ 中文 UI / API / 外部 Adapter / Status
```

运行面使用 OVH + SQLite；长期结构化事实进入 Private-Database，大对象进入 R2，D1 只作可重建冷索引，OCI 作异地冷备。Status 是当前运行状态的只读投影与首尾控制入口，但不是第二业务数据库。

任务包状态为 `SEALED_TASKPACK`；`FROZEN_CANDIDATE` 与 `VERIFY_AND_RELEASE` 由目标环境和独立验收阶段产生。
