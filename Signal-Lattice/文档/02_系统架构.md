# 02｜系统架构

```text
systemd timer（60 秒） → signal-lattice once
  → marketdata/（新浪、腾讯报价与日线；天天基金净值）
  → live_runtime 新鲜度门（按交易时段秒数，午休/收市不计）
  → backtest/ walk-forward（S1/S2 选参与推广门）
  → branches/（s1_momentum、s2_meanrev、lead_lag）→ aggregate + weighting
  → JSON 账本 /var/lib/signal-lattice-v2
signal-lattice serve（127.0.0.1:8787）→ web/ 页面每 30 秒轮询 /api/v1/report/latest
Cloudflare 隧道 → https://signal-lattice.linzezhang.com
```

运行时零第三方依赖（仅标准库）。安装：`scripts/build_wheel.py` → `scripts/install_release.sh`（不可变 release 目录 + current/previous 软链）；回滚 `scripts/rollback.sh`。
