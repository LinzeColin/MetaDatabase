# 01｜产品需求

## 用户问题

股票研究方法分散、证据重复、Skill 持续变化、结论难以复现，且研究容易被误当作直接交易信号。

## 价值

- 动态接入平权 Skill；
- 对来源、版本、证据、冲突和时间进行追踪；
- 用 Point-in-time、样本外、费用和流动性硬门验证；
- 给出可解释的 Action Packet 或 `NO_ACTION`；
- 用 Status 管理所有业务线的阶段、状态和耦合；
- 将 Build Agent 的工作压缩为真实凭证、写权限、环境兼容、部署和收尾。

## 非目标

不自动交易，不使用运行期 LLM，不新增公共多租户、复杂账号、期权、加密货币、Kubernetes或第二权威数据库。当前任务包不声称已经证明真实市场优势。
