# 06｜运维手册

## 服务

API、Worker、Source Sync、Evolution、Outbox Sync、Status 和 Backup 由 systemd 管理。无 launchd、无 Agent 会话、无人工保活、无运行期模型 Token。

## 常用命令

```bash
bash scripts/codex_last_mile.sh plan
bash scripts/codex_last_mile.sh preflight
bash scripts/codex_last_mile.sh verify
systemctl status 'signal-lattice*'
journalctl -u 'signal-lattice*' -n 300 --no-pager
bash scripts/diagnostics.sh /tmp/signal-lattice-diagnostics.txt
signal-lattice backup /var/lib/signal-lattice/backups/runtime-latest.db
sudo bash scripts/rollback.sh
bash scripts/codex_last_mile.sh close
```

## 降级

上游、Provider、数据、License、量化、独立复审或 Status 任一关键证据不足时，保持服务可读但强制 `RESEARCH_AND_NO_ACTION`。不得通过配置绕过零 Token、零 Agent 或自动交易边界。
