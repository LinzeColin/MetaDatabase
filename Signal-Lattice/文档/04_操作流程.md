# 04｜操作流程

## 本地开发

```bash
python3 -m venv /tmp/venv-sl && /tmp/venv-sl/bin/pip install pytest setuptools
cd Signal-Lattice && PYTHONPATH=src /tmp/venv-sl/bin/python -m pytest -q -p no:cacheprovider tests
PYTHONPATH=src SIGNAL_LATTICE_STATE_DIR=/tmp/sl-state python3 -m signal_lattice.cli once   # 需要能访问新浪/腾讯
```

## 发布

1. PR 合入 main（`signal-lattice-ci.yml` 绿）。
2. 生产机上：`sudo bash Signal-Lattice/scripts/deploy_v2.sh`。
3. 交易时段跑 06 的业务判据命令。
