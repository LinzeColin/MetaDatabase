## AC-028 是 NOT_RUN

「R2 与 OCI 各有可验证对象；第一份不可读时第二份可在隔离目录恢复并核对关系。」

这条要真实对象。本地能造出一个「两个目录互为备份」的场景并让它通过，
但那证明的是本地目录能读能写——**不是 R2 坏了 OCI 能顶上**。

实测缺失见 `not-run-receipt.json` 的 `probes`：
生产机连不上，R2 / OCI / Cloudflare / GitHub 凭据全部未设置。

## 凭据到位后跑什么

1. 断开 R2 访问 → 触发一次备份 → 确认回执是**失败**而不是成功
2. 把 R2 对象设为不可读 → 从 OCI 在隔离目录恢复 → 核对两份关系
3. 恢复期间 `kill -9` → 重启 → 确认没有半份快照被当成完整的
