# 浏览器伴随组件（S13/P02）

该组件是本地、最小权限的即时校验制品：用户点击扩展后，它只读取当前激活页面中明确标记为 `data-abd-visible-field` 的可见字段，并比较赛事、盘口、选择、赔率、可用时间与风险开关。它不请求网络、不持久化页面内容、不自动打开平台、不自动点击，也没有订单提交能力。

默认没有站点权限或真实平台选择器。未安装组件、页面无明确可见字段、没有本地 ticket，或任一字段不符时，结果必须是红色撤销而非推测通过。实际平台适配、来源合同、扩展安装与真实浏览器运行证据均不在 S13/P02 的本地冻结验收范围内。

`quote_check.py` 是本阶段的 Python 确定性参考判定器。伴随组件只在本地 session 接收同一 ticket，并采用固定精度字符串比较；它不会把网页文字当作指令。
