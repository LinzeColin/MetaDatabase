# Working Backwards PR/FAQ

股势前瞻为现有股票系统增加一个可审计、可回放、会主动拒绝预测的节点。它在明确的 5D/20D/60D 周期内返回正净收益概率、基准增量、收益分布、首次触及时间结构和证据状态；输入或证据不合格时返回 `ABSTAIN`。它不联网、不下单、不持续运行 Agent，也不消耗 LLM Token。

**为什么 EFS 不能独自决定买卖？** EFS 是绝对正净收益概率；还必须看 Baseline/Lift、经济 Edge、可靠性、样本支持和宿主风控。

**为什么 70 分仍可能没有 Alpha？** 若冻结基准为 71%，Lift 为负；高概率不等于增量价值。

**是否已经证明能赚钱？** 没有。旧基线未超过 null model；v0.0.0.1 能力上限是 Shadow。

**为什么仍值得发布？** 它将 PIT、校准、成本、时间、证据成熟度、拒绝预测、模型晋级和恢复边界变成统一可验证合同，避免重复产生不可审计的“神秘分数”。

**是否占用 Owner 的 Mac？** 不占用上线后的本机持久或常驻资源。生产仅在既有远程宿主按需执行；禁止 macOS 安装和 `launchd`。落库确认后删除下载 ZIP。显式函数运行瞬间必然使用短暂 CPU/RAM，但调用结束后不留下文件、缓存、日志、状态或进程。
