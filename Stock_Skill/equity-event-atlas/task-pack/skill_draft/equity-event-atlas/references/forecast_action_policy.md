# 预测与动作政策

## 1. 价格影响框架

```text
事件影响 =
意外程度 × 预期差 × 实际供需 × 流动性与拥挤度
× 市场环境 × 多事件交互 × 时间衰减
```

该式是分析框架，不是可直接拟合的万能公式。每个因子必须说明证据、代理变量和未知项。

## 2. Bull / Base / Bear

预测门为 `PASS` 时，必须且只能提供三个情景：

- 概率和为 1；
- 期限使用交易日；
- 每个时点提供 `low <= mid <= high`；
- 说明方法、历史样本数和置信度；
- 每个情景至少一个失效条件；
- 不把区间中点称为必达目标价。

样本量小、事件异质性高、市场结构变化或数据许可不明时，降低置信度或阻断预测。

## 3. 历史研究最低要求

- 事件定义在研究前冻结；
- 估计窗和事件窗明确；
- 使用当时可得信息；
- 调整拆股、股息、停牌与交易日；
- 至少说明市场或行业基准；
- 披露筛选偏差、幸存者偏差和多重检验；
- 不从大量窗口中只挑最好看的结果。

## 4. 动作政策

主动动作：`AVOID / HOLD / REDUCE / ACCUMULATE / HEDGE / EXIT`。

非主动动作：`WATCH / NO_ACTION / RESEARCH_ONLY`。

主动动作要求：

1. 市场能力为 `FULL` 或 `SUPPORTED_WITH_HOST_DATA`；
2. 身份、证据、预测和动作门均为 `PASS`；
3. 用户约束充分；
4. 有前置条件、规模、触发、风险上限、失效条件；
5. 规模使用当前仓位或计划仓位百分比；
6. 不因税务未知、流动性未知或权限未知给出确定性动作。

## 5. 默认目标函数

默认不是“理论最大利润”，而是：

> 在用户风险预算、流动性需求、最大事件敞口和已知约束下，最大化风险调整后的预期效用。

当证据不足或事件已充分定价时，`NO_ACTION` 是合格结果。

## 6. 校准

冻结 `forecast_id`、概率、区间、时点与证据哈希。期限结束后记录：

- 事件是否按预计状态发生；
- 实际路径是否落入区间；
- 概率误差和可靠性分桶；
- 方向性偏差；
- 哪类来源或事件持续高估/低估。

不得删除失败预测或用新信息改写旧概率。
