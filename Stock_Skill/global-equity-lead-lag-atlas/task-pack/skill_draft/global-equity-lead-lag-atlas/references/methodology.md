# 方法说明

## 1. 两类关系必须分开

### 同期相关

对每个无向市场对和每个收益尺度，计算双方按相同 `session_date` 对齐的历史累计对数收益相关性。该视图是对称的，只描述共同变动，不表达谁领先谁。跨市场节假日通过共同日期交集处理；因此结果必须同时报告样本量与有效样本量。

### 会话感知时延

对目标市场会话 `t`，只允许使用 `source.close_ts_utc < target.open_ts_utc` 的最后一个来源收盘；在此基础上可再后移 `source_lag` 个来源会话。来源特征为截止该来源收盘的 `horizon` 期历史收益，目标结果为从目标前一收盘到未来第 `horizon` 个目标收盘的收益。

这两个结果不能互换：同期相关不能判断先行者；方向时延也不能代替普通同周期相关。

## 2. 三个时间概念

- **收益尺度 `horizon`**：1、5、10、15、21、63、126 个市场自身交易会话的累计收益。
- **估计区间 `lookback`**：由宿主截取输入数据控制，本核心不静默改变。
- **额外来源滞后 `source_lag`**：在“目标开盘前最后一个已完成来源收盘”基础上，再后移若干来源会话。

`max_base_staleness_hours` 只约束目标开盘前最后一个可用来源收盘的基础陈旧度，默认 96 小时；它不把额外会话滞后错误当作数据陈旧。

## 3. 多重检验和两阶段确认

同期相关与时延假设分别执行全局 Benjamini–Hochberg 校正，避免一类结果的假设数量污染另一类。两类结果都先检查样本、效应量和 FDR；通过初筛者才执行确定性循环区块 Bootstrap 与滚动符号稳定性。方向时延还必须通过 70/30 样本外线性预测比较。

同期相关确认条件：

1. 原始和有效样本量阈值；
2. 绝对效应量阈值；
3. FDR q 值阈值；
4. 区块 Bootstrap 95% 区间不跨 0；
5. 滚动方向稳定性。

方向边在上述条件外还要求样本外 MSE 改进。

## 4. 有效样本

重叠 `horizon` 期收益具有强序列依赖。本版以 `floor(N_raw / horizon)` 作为保守有效样本下界；这不是完整自相关校正，但比把全部重叠观测视为独立更诚实。宿主研究版可替换为 HAC、stationary bootstrap 或预注册非重叠样本 Adapter。

## 5. 指数身份与收益类型

本 Skill 的默认对象是本地现金市场基准指数，输入必须声明 `instrument_type=cash_index`。在美国等异地上市的国家 ETF 与本地指数处于不同交易时段，会污染真实会话先后，因此默认拒绝作为国家市场主代理。

输入还必须明确 `return_type` 为 `price`、`total_return` 或 `net_total_return`；一次分析不得混用。价格指数与全收益指数的差异可能被误判为国家间结构性背离，不能静默归一。

## 6. 币种口径

`currency_mode=local` 表示各市场维持自己的本地币种；跨国相关中包含汇率之外的本地市场表现。`currency_mode=usd` 不负责现场换汇，要求宿主先把全部指数序列统一为 USD 且输入 `currency=USD`。系统拒绝静默混合。

## 7. 结论边界

统计相关、预测增量或时间先后均不自动证明现实因果。共同全球因子、行业权重、汇率、指数重构、数据时间戳误差和制度切换都可能解释关系。本版本不输出因果结论或交易建议。
