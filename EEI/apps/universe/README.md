# 商域宇宙（EEI 沉浸式宇宙视图）

每家核心公司是一颗恒星，它在官方申报里的子公司、董事、股东是行星；同一实体出现在两家公司的关系里时，
拉出一道穿越星海的金色光弧（宇宙关联）。点击恒星飞入星系，点击行星看关系与 SEC / GLEIF 官方原文链接。

- 纯静态页面：`index.html` + `app.js` + `styles.css`，three.js r170 固定版本放在 `vendor/`，运行时不依赖外部 CDN。
- 数据全部实时读 EEI 公开接口（默认 `https://eei.linzezhang.com`，CORS 已放开；可用 `?api=` 覆盖），页面不写死业务数字。
- 浏览器不支持 WebGL 时给出中文说明与平面版入口；`prefers-reduced-motion` 下关闭动效。
- 怎么看它活着：打开页面，左上角「数据截至」时间应在一天内，绿点在呼吸。
