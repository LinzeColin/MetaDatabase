# 运维手册

怎么把它跑起来、参数在哪调、报错了怎么办、都改过些什么。

## 一、怎么跑

改完机器平面，按顺序跑这三条，让人类平面刷新并过关：

```bash
python3 machine/tools/render_human.py            # 先渲染人类平面
python3 machine/tools/check_doc_budget.py        # 体积、中文、纯净三道门
python3 machine/tools/check_blocker_stop.py      # 阻塞重审门
```

## 二、参数在哪调

改一个参数要动哪个文件，都在这。为什么定这个值在 `02_系统架构.md`。

| 参数 | 当前值 | 改哪里 |
|---|---|---|
| 数据目录 | `$PFI_DATA_DIR`（建议 `~/.pfi/data`） | 环境变量，或命令行 `--data-dir` |
| 分类覆盖规则 | `$PFI_DATA_DIR/rules.json`（可选） | 数据目录下的 `rules.json` |
| 币种 | 支付宝 `CNY`，CBA `AUD`，分开统计 | `PFI/src/pfi_os/importers.py` |
| 界面端口 | 8501 | `python -m pfi_os app --port` |

## 三、报错了怎么办

| 遇到什么 | 为什么 | 怎么解决 |
|---|---|---|
| 提示缺少数据目录 | 没设 `PFI_DATA_DIR` 也没传 `--data-dir` | `export PFI_DATA_DIR=~/.pfi/data` |
| 提示找不到支付宝表头 | 文件不是支付宝交易明细导出，或导出列名变了 | 确认表头含 交易时间、收/支、金额 三列 |
| 提示压缩包已加密 | 支付宝邮件里的账单压缩包带密码 | 先用支付宝给的解压密码解压，再把表格放进数据目录 |
| 拉取失败 | 本机 `gh` 未登录或无私有仓读权限 | `gh auth login` 后重试 `python -m pfi_os pull` |
| 某些文件被跳过 | 既不是支付宝也不是 CBA 格式 | 报告开头列出了被跳过的文件名，确认后移走 |
