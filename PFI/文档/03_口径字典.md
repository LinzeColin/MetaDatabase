# 口径字典

## 一、关键数字口径

| 项 | 裁定 | 状态 |
|---|---|---|
| 支出 | 性质为消费的流出金额之和（正数） | 已实现 |
| 退款 | 性质为退款的流入金额之和；支付宝“不计收支”的退款镜像行不计 | 已实现 |
| 净支出 | 支出 − 退款 | 已实现 |

| 投资净流 | 基金、余额宝、券商、贵金属有方向的资金流之和，负数为净买入；“不计收支”行无方向不计 | 已实现 |

| 需复核 | 支付宝收/支方向未知，或消费无法归类 | 已实现 |
