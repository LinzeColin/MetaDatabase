## 二、数据从哪到哪

私有仓 `Private-MetaDatabase`（数据域 `LinzeDatabase-alipay`）→ `pull` → 本机 `$PFI_DATA_DIR` → 导入（识别来源、去重）→ 分类 → 月度汇总 → 报告 / 本地界面 / 逐笔导出。全程只读原始账单，不写回私有仓，不把任何数据落进代码仓。

## 三、关键参数为什么这么定

当前值和改哪里在 `06_运维手册.md`，这里只讲**为什么是这个值**。

| 参数 | 为什么定这个值 |
|---|---|
| 数据目录 | 真实流水只在仓外；代码不写死任何本机路径。 |
| 分类覆盖规则 | 内置关键词覆盖不了所有商户；个人规则放在数据目录，不进仓。 |
| 币种 | 没有可信汇率来源时不换算，避免伪精度。 |
| 界面端口 | 只监听本机 127.0.0.1。 |

## 四、数据长什么样

| 数据 | 关键字段 | 主键 |
|---|---|---|
| 流水 | `source`, `occurred_at`, `amount`（负数流出）, `currency`, `direction`, `counterparty`, `description`, `source_category`, `status`, `order_id` | 支付宝 `order_id`；CBA 为日期+金额+描述+同文件出现序号 |
| 分类结果 | `kind`, `category`, `reason`, `needs_review` | 随流水 |
| 月度汇总 | `month`, `currency`, `income`, `expense`, `refund`, `net`, `investment_net`, `categories` | `month` + `currency` |
