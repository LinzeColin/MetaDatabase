# JobHuntBot Online v0.4.0

一个全中文、多账户、多用户的候选人智能求职系统。它不是另一个招聘信息网站，而是在多个合法岗位来源之上，为每个候选人完成资格判断、个性化排序、岗位对应简历、申请材料和全过程记录。

本版本以金融与法律求职者作为首要验证样本，同时保留数据、运营、业务分析等通用岗位能力。

## 核心用户流程

```text
邮箱注册与验证
→ 上传一份或多份简历
→ 集中确认少量高影响事实
→ 自动聚合并每六小时刷新岗位
→ 先检查硬资格，再排序相关性与机会潜力
→ 按领域、城市、岗位、技能和新鲜度筛选
→ 每个岗位自动选择最合适的简历
→ 下载事实可追溯的岗位定制 DOCX
→ 手动到官方页面申请并记录结果
```

## 本版本的关键差异

### 金融岗位

识别金融分析、会计与审计、投资与银行、风险管理等方向，并核对：

- Graduate、Junior、Senior、Director 等职级；
- 明确要求的经验年限；
- CPA、CA、CFA、ACCA、CIMA、RG146 等专业资质；
- 工作权利与雇主担保。

### 法律岗位

识别法律、合规、合同与法务运营等方向，并核对：

- LLB、JD、PLT；
- 澳大利亚律师准入；
- 有效执业证书；
- 律师岗位年限和管理级别；
- 工作权利与雇主担保。

### 岗位对应简历

系统保留用户上传的全部简历。生成申请包时，它会按岗位族、领域、技能和明确资质要求重新比较每份简历，而不是机械使用最后上传的默认版本。选择原因和替代版本可见，原始简历不会被覆盖。

### 可实际使用的申请文档

申请包可下载岗位定制 DOCX，包含岗位适配摘要、核心技能、相关经历、教育、专业资质、已覆盖要求和待确认缺口。文档只使用候选人已上传和确认的事实。

## 已保留的基础能力

- 邮箱注册、验证、登录、忘记密码和密码重置；
- 租户隔离、账户删除、管理员用户和额度管理；
- 平台统一人工智能服务，普通用户不接触密钥；
- 多来源岗位发现、标准化、去重、来源故障隔离；
- 严格每六小时刷新；
- 推荐筛选、收藏、忽略、手工岗位导入；
- 申请包、申请状态、证据和备注；
- PostgreSQL、迁移、备份、恢复和应用回滚。

## 邮件和平台边界

NitroSend 不是依赖。账户邮件使用任意标准 SMTP；暂缺 SMTP 时可关闭公开注册并继续其他部署。系统不保存第三方招聘平台账号，不绕过验证码或平台限制，不自动最终提交申请。

### 邮件防骚扰保护

生产环境按收件人至少间隔 30 分钟、24 小时最多 3 次，并以不可逆的收件人查找摘要计数；删除和重新注册账户不会重置该限制。真实邮件验收必须使用两个不同的专用测试邮箱、一次性运行标识与 24 小时冷却，禁止自动重试、缩短间隔或把未投递邮件写成已发送。
