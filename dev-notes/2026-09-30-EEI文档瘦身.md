## 校验清单怎么重生成（不要手改哈希）

```bash
git add EEI                              # 清单从 git ls-files 生成，新文件必须先进暂存区
cd EEI
make generate-clean-room-release         # 重打清洁室 ZIP 与证据 JSON
make generate-release-artifacts          # 重生成 manifest.txt / DIRECTORY_TREE.txt / CHECKSUMS.sha256 / release_evidence
cd .. && git add EEI                     # 生成物再进暂存区（顺序不可颠倒，见 dev-notes/经验-202608.md）
```

`apps/universe/` 按前缀被排除在清洁室 ZIP 与清单之外，改它不需要重生成。
