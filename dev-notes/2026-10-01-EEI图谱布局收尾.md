# EEI 旧版图谱：布局收尾（2026-09-30）

分支 `cloud/eei-graph-layout-261001`，接 #397。只改 `EEI/apps/web/src/app/globals.css` 与 `page.tsx`，截图在 `dev-notes/assets/eei-graph-layout-261001/`。所有改动只在云发布面（`CLOUD_MODE` 或 `.workspace[data-cloud-surface="true"]`），样例工作台（A167 基线）不变。

## 五处问题

1. **手机首屏**：图谱 svg 前面加了一条「主体名 + 6 家实体 · 8 条关系 · 数据截至」（只在 <=767px 显示，对读屏隐藏，避免和左栏重复朗读）。svg 由固定取景 `0 0 760 480` 改成按节点包围盒取景（`cloudFit`），节点和标签约放大到原来的两倍，高度按比例留，不再留大片空白。
2. **桌面 HUD 被节点球盖住**：图谱 svg 是 `position:fixed` 且层级高于画布顶部控制条。现在 `page.tsx` 量出控制条底边写进 CSS 变量 `--cloud-hud-bottom`，图谱从它下面开始；左边让出 60px，避免被左下图例挡住。1440 / 1280 / 1024 都看过。
3. **关系表格**：右栏只有约 250px 宽，8 列表格每列 1–3 个字。云发布面改成每条关系一张卡片（列名用伪元素标注，重复的「方向」列只留给读屏）。桌面整页高度 5217px -> 4896px，每条关系的行高由上百像素降到约 190px。
4. **左栏新鲜度小方块**（`.freshnessGrid`）：浅底改深底，长时间戳允许折行。
5. **样例日期残留**：云模式网址不再写 `asOf`；「保存视图」卡「透镜 / 时间」「备注」、诊断里的「快照」、关系表格「时间」列，改显示数据版本日期（`publishedDataVersion`）。整页文字里 `2026-06-19` 出现次数：改前 10，改后 0。
