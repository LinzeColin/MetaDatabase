# 微信读书笔记迁移：路径级开发规则

父级仓库规则继续有效；本文件只收紧当前应用。

## 不可变产品合同

- 不得提交、持久化、记录、追踪、分析或暴露真实微信读书密钥、原始笔记响应、导出笔记、压缩包或用户身份。
- P0 无 D1、无服务端用户状态；用户只在当前浏览器会话使用本人绑定的 `wrk-…` 密钥。
- 服务端代理只能调用 `src/core/constants.js` 冻结的腾讯官方接口地址、接口白名单和参数白名单。
- 每个上游请求必须携带冻结的官方技能版本；响应包含 `upgrade_info` 时立即停止受影响操作。
- 上游或业务失败不得变成空结果或看似完整的成功导出。
- 必须保持确定性导出、稳定文件名、路径安全、受保护补充区、部分失败报告和离线搜索。
- P0 只提供匿名导出；不得加入登录、账户或服务器端用户笔记库。
- `/privacy/`、`/terms/` 和 `/status/` 必须保留无需 JavaScript 可读的中文预渲染正文；不得退化为同一空壳页面、失效锚点或占位文案。
- `/healthz` 只证明存活，`/readyz` 必须验证静态资源真实可读，`/api/status` 必须脱敏且不得使用用户密钥探测上游；三者不得合并为永远健康的假状态。
- 业务线治理合同以 `src/core/business-governance.js` 为唯一运行时来源；`/status/`、`/api/status`、`/readyz`、OVH 状态适配和生产 Smoke 必须保持同一七条业务线、依赖图与状态语义。未实证、外部受控和阻塞不得伪装为可用。
- 演示数据只用于体验和确定性验收；生产主入口必须是本人微信读书连接，且运行状态未确认时不得伪装真实连接可用。
- 所有最终用户可见界面、错误、帮助、导出说明和运维展示默认使用简体中文；标准名、软件名和机器标识可保留英文，但必须有中文语境。

## 零等待执行

- 不得把真实时间浸泡、观察期、Alpha/Beta/GA 等待、重复审批、人工签字、非必要集成或广覆盖测试设为部署前置条件。
- 核心确定性验证通过后立即部署匿名核心到 Sites 默认生产网址；广浏览器、负载、混沌、恢复和时间型验证应实现为可立即手工触发的 CI 或 systemd 自动任务，并在上线后继续积累证据。
- 只能因已证实的密钥/隐私泄漏、跨用户访问、缺少生产写权限、真实资源耗尽、不可逆数据损失、明确法律/平台禁止或经常性成本越界而暂停最小受影响范围。
- 普通构建错误、依赖问题、测试失败或合并冲突不得触发重新研究。Codex 只记录最小事实、日志与路径；由任务包维护者准备确定性修复后，Codex 原样应用、验证、commit、push 与部署。
- Scope、Acceptance、测试集和 Definition of Done 已冻结；每个最大阶段最多 2 轮整改和 1 套最终自动盲测，同类问题必须合并。封包前复审已完成，开发 Agent 不得再次调用或委托 Verifier、Teleiosis、Persona、SubAgent、第二模型或人工 Reviewer。
## 当前阶段与后续账户化边界

- 本次 Stage 1 只生产化匿名、浏览器本地优先的 P0；账户、登录、服务端用户库、跨平台 OAuth 和用户画像不进入本补丁。
- P1 账户化必须先由 Owner 明确授权修改本产品合同，并选定可承担会话、撤销、加密和用户删除的持久身份权威；GitHub、R2 与 OVH 临时 SQLite 均不得被误用为在线身份数据库。
- Notion、Google 与 GitHub 连接器必须使用各自正式 OAuth/OIDC 或 GitHub App 授权；Obsidian 默认按本地 Vault/文件夹/ZIP 导入，不伪造不存在的集中式“Obsidian 登录”。
- 任何曾在聊天、工单、日志或公开文本出现的真实测试密钥均视为已泄露，不得写入代码、任务包、CI、Sites、日志或夹具；必须撤销并轮换后才允许真实密钥 E2E。
